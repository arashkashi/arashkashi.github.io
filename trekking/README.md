# TrekkingMap — Liguria

A hut-to-hut hiking planner for Liguria, Italy, built on OpenStreetMap data.
Live at <https://arashkashi.github.io/trekking/>.

Plan a route by clicking waypoints, split it into days that end at real mountain
huts, import a GPX and see it coloured by steepness, and search ~5,500 named
features offline. Huts load progressively as you pan and are cached locally.

Map data © OpenStreetMap contributors (ODbL). Topographic rendering ©
OpenTopoMap (CC-BY-SA). Elevation from SRTM via AWS Terrain Tiles.

Example route *Giro del Marguareis* by Giorgio Bernardi, Piemonte Outdoor /
VISITPIEMONTE, via [outdooractive](https://www.outdooractive.com/r/58321831).

Source and data pipeline are kept separately; this directory holds the built
site only.
